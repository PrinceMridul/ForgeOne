# @forgeone/web

The ForgeOne execution console — a TanStack Start (React 19) app that streams a
run agent by agent and lets you browse and download what the pipeline produced.

This is one workspace of a pnpm monorepo. Run it from the repository root:

```bash
pnpm install
pnpm turbo dev          # web :8080 · api :4000
```

The Vite dev server proxies `/api/v1` and `/health` to the Fastify API on
`:4000`, so the browser stays same-origin and no CORS preflight is involved.
The same paths are proxied in production by `src/lib/api-proxy.ts` — see
[DEPLOYMENT.md](../../DEPLOYMENT.md).

## Layout

| Path | Contents |
|---|---|
| `src/routes/` | File-based routes. `run.tsx` is the live execution console. |
| `src/components/` | Feature components — pipeline flow, artifact explorer, repository tree, build verification |
| `src/components/ui/` | shadcn/ui primitives |
| `src/lib/api-client.ts` | Typed fetch wrapper for the API |
| `src/lib/api-proxy.ts` | Production reverse proxy, mounted in `src/server.ts` |
| `src/lib/live-engine.ts` | Turns polled run telemetry into console state |
| `src/routeTree.gen.ts` | Generated by the TanStack Router plugin — do not hand-edit |

## Scripts

```bash
pnpm --filter @forgeone/web dev          # Vite dev server
pnpm --filter @forgeone/web build        # nitro node-server build -> .output/
pnpm --filter @forgeone/web lint
pnpm --filter @forgeone/web type-check
```

## What is real and what is illustrative

The run console, artifact explorer, repository views and build-verification
panel are driven entirely by live run data. A few workspace screens are
illustrative and carry a *Sample data* badge in the UI. If you make one of them
real, remove its badge.

## Built with

TanStack Start · React 19 · TypeScript · Vite · Tailwind CSS v4 · shadcn/ui ·
Lucide · Recharts

The initial route skeleton and the `src/components/ui/` primitives were
scaffolded with [Lovable](https://lovable.dev); everything under
`src/components/` and `src/lib/` that touches run data was written for this
project.
